# SHPE Funding Discovery

Local-first sponsorship intelligence prototype for finding organizations near a university,
scoring their fundraising potential, and showing the evidence behind each score.

## Current demo centers
- Florida Polytechnic University
- Dartmouth College

Each center supports **10-mile** and **25-mile** discovery radii.

> This repository is an MVP. Scores are deterministic and evidence-backed; the score is not generated by an LLM.
