# Scoring model

The Sponsor Score is a deterministic weighted score from 0 to 100.

| Metric | Weight |
|---|---:|
| Philanthropy & community giving | 25% |
| STEM / education alignment | 15% |
| Recruiting / student talent | 15% |
| Previous sponsorship behavior | 10% |
| Industry relevance to SHPE | 8% |
| Local presence | 7% |
| Financial capacity | 6% |
| Geographic proximity | 5% |
| University engagement | 4% |
| DEI / SHPE alignment | 3% |
| Evidence quality / recency | 2% |

## Design principles
1. Missing evidence is not automatically a negative fact.
2. Every evidence-backed signal should retain a source URL.
3. The score stays deterministic even if a future local LLM helps classify pages.
4. Human review remains required before fundraising outreach.
